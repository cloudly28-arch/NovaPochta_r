# Nova Poshta Wholesale Warehouse Backend — Stage 1

Первый каркас backend-проекта на C++17 для моделирования работы оптового склада.

## Реализованные сущности

- `Worker` — сотрудник склада и его роль.
- `Store` — магазин/получатель товара.
- `Product` — товар.
- `InventoryItem` — остаток товара и ячейка хранения.
- `OrderItem` — позиция заказа.
- `Order` — заказ магазина со статусом.
- `Warehouse` — агрегирует работников, магазины, товары, остатки и заказы.

## Уже есть базовая логика

- добавление работников, магазинов и товаров;
- защита от повторяющихся ID;
- прием товара на склад;
- хранение количества товара по позициям;
- создание заказа;
- проверка достаточности остатков;
- списание товара при подтверждении заказа;
- изменение статуса заказа;
- поиск сущностей по ID.

## Сборка

```bash
cmake -S . -B build
cmake --build build
./build/warehouse_backend
```

Или напрямую через g++:

```bash
g++ -std=c++17 -Iinclude src/*.cpp -o warehouse_backend
./warehouse_backend
```
